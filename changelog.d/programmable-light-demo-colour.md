### Added
- **The Explorer lets a reader try a colour on a light the user colours.** The tree
  row of a lamp the model marks `programmable` gains a colour box and a `clear`
  chip. The choice paints that lamp in the drawing, through the lamp-colour
  variable a lamp's state colours use, and in the 3D scene, and is a viewing
  choice only: it is in no link, field or export, and a device loaded afterwards
  starts without it. `kit/states.js` gains three small functions the page uses
  (`programmableOf`, `demoHex`, `demoColours`). No library device carries the mark
  yet, so no drawing, index entry or export changes. This closes the last open
  item of the issue's own list: the optional demo colour per port in the Explorer.
