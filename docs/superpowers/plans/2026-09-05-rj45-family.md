# RJ45 Family Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the library's nine RJ45 components with two bare jacks and two lamped ones, drawn from manufacturer drawings, and move every RJ45 placement and its in-jack lamps onto them.

**Architecture:** `std/rj45@2` and `std/rj45-ganged@2` are the jack housing and the ganged cell, each with a three-tier 8P8C cavity recessed into solid walls. `common/rj45-eth@1` and `common/rj45-ganged-eth@1` compose those `behind: true` and add two lamps in the keyway-side corners. A textual sweep tool moves placements by role, holds every jack's centre, lifts the 556 separate lamp placements into per-element `states:` on the jack, resizes cutouts, and bumps versions. A census lint rule (L76) keeps the convention from growing back.

**Tech Stack:** Python 3 (PyYAML for reading, textual edits for writing, as every sweep tool in `spec/tools/portrayal/` does), pytest, the repo's own `lint.py`, `render.py`, `devicelock.py`, `build.sh`, `publish.sh`.

**Spec:** `docs/rj45-family-design.md` (approved 2026-09-05). Read it first; every figure below is argued there.

## Global Constraints

- Every dimension carries a `confidence` and a `source` naming the drawing. The drawings are at `working/intake/standards/rj45/` (gitignored); cite them as `TE 1734264 rev A2`, `TE 6368011 rev L`, `Amphenol Canada modular jack catalogue (RJHSE-508X)`.
- The three-tier cavity: body `11.91 x 6.83`, shoulder `6.30 x 1.69`, latch slot `4.06` wide running to the housing's lower edge. Housing `15.8 x 13.2`, depth `18.6`. Ganged cell `12.7 x 11.0`, pitch `13.97`, unchanged.
- Lamp windows: `2.0` wide, `1.1` high, `1.2` in from each side, `0.27` from the keyway edge. Default states `['off', link, activity]`, no colour keys.
- Unrotated is pins up, keyway down. `rotate: 180` at placement flips both. This is the existing convention; do not change it.
- Every anchor move holds the jack's centre. A placement's `at` changes only by half the size difference between old and new part.
- Removing an id from a device is a MAJOR bump; a composed-only change is a PATCH; devicelock says which. Run `devicelock.py --update` only after bumping.
- YAML files are edited textually (regex on the flow-style lines), never by `yaml.dump`. See `sweep_ids.py`'s docstring for why.
- Gates before every commit that touches `library/`: `python3 spec/tools/portrayal/lint.py --schemas spec/schemas --library library` ends `LINT: ok`; `python3 -m pytest spec/tests -q` passes; `python3 spec/tools/portrayal/devicelock.py --library library` reports `0 finding(s)`. Before a PR: `./publish.sh --no-images` and `git diff --quiet -- library/exports`.
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. PR bodies end with `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.
- Branch off `origin/main` for each PR. Do not use bare `git stash`.

def contract(ref):
    nsname, major = ref.rsplit("@", 1)
    return yaml.safe_load((LIB / "components" / nsname / f"v{major}" / "contract.yaml").read_text())


def skin(ref, name="default"):
    nsname, major = ref.rsplit("@", 1)
    return (LIB / "components" / nsname / f"v{major}" / "skins" / f"{name}.svg").read_text()


def cavity_path(ref):
    m = re.search(r'id="cavity"[^>]*\bd="([^"]+)"', skin(ref), re.S)
    assert m, "no cavity path"
    return m.group(1)


def tier_widths(d):
    """The horizontal runs of an evenodd cavity path, largest first. A three-tier
    opening drawn as one outline has runs of the body, shoulder and slot widths."""
    runs = {abs(float(x)) for x in re.findall(r"h\s*(-?[\d.]+)", d)}
    return sorted(runs, reverse=True)


def test_std_rj45_v2_is_the_housing():
    c = contract("std/rj45@2")
    assert c["version"].startswith("2.")
    assert c["size"] == {"w": 15.8, "h": 13.2, "d": 18.6}
    assert c["conforms"] == "rj45" and c["interface"] == "rj45"

### Task 8: `sweep_rj45.py`, the migration tool

**Files:**
- Create: `spec/tools/portrayal/sweep_rj45.py`
- Modify: `spec/tests/test_rj45_family.py`

**Interfaces:**
- Consumes: `lint.RJ45_BARE`, `lint.rj45_wants_lamps`, `lint.contract_size(ref, roots)`, `lint.resolve_component`, the four new refs.
- Produces: a CLI `sweep_rj45.py --library library [--apply] [--components] [device-or-component fragments...]` that prints a per-file report and, with `--apply`, rewrites files textually. Tasks 9-14 run it.

What it does to a device file, in order, all textual:

1. **Map every RJ45 placement.** Old ref → new ref by `rj45_wants_lamps`: any of `std/rj45@1`, `common/rj45-port@4`, `common/rj45-bezel@2`, `common/rj45-shielded@1`, `common/rj45-shielded@2`, `common/rj45-jack@2` → `common/rj45-eth@1` or `std/rj45@2`; any of `std/rj45-ganged@1`, `common/rj45-hd@1`, `common/rj45-hd-plain@1` → `common/rj45-ganged-eth@1` or `std/rj45-ganged@2`.
2. **Hold the centre.** New `at = old_at + (old_size - new_size) / 2` per axis, using `lint.contract_size` for both refs, rounded to 2 dp. Rotation does not change this: both sizes are pre-rotation.
3. **Lift in-jack lamps.** A placement whose ref resolves to `class: led` and whose `for:` names an RJ45 placement being moved to a LAMPED ref, and whose `at` lies inside that jack's old footprint, is REMOVED. Its `states:` (a list) or, absent that, a `{name: <attrs.function>}` entry, goes into a per-element mapping on the jack: lamps sorted by x within the jack; the lower-x one is `led-a`, the other `led-b`. If a removed lamp carried neither `states:` nor `attrs.function`, nothing is added for it (the component default stands). Write the mapping as `states: {led-a: [...], led-b: [...]}` appended inside the jack's flow mapping before its closing `}`.
4. **Re-point legends.** Every `for: <removed-lamp-id>` and `for: [.., <removed-lamp-id>, ..]` in `silkscreen:` becomes the jack's id (deduplicated). Any other reference to a removed id (regions `members`, gaps `scope`, `combo-with`) is reported, not rewritten.
5. **Resize cutouts.** A `panel.cutouts` entry whose id is a moved jack takes the new part's `size` (`[15.8, 13.2]` or `[12.7, 11.0]`), and its `at` moves by half the size difference so the hole's centre holds.
6. **Bump the version.** If any id was removed: major (`X.Y.Z → X+1.0.0`). Else if any placement moved: minor (`X.Y+1.0`). Written on the `^version:` line.
7. **Report**: file, jacks moved (bare/lamped), lamps lifted, legends re-pointed, cutouts resized, bump, and any reference to a removed id it could not rewrite.

With `--components`, the same steps 1-2 and 6 (minor bump) apply to `parts:` lists in component contracts (Juniper cards, Cisco RSPs, Casa SMMs, Dell). Cards have no cutouts or lamps to lift; report `parts moved`.

Textual mechanics, copied from `sweep_jack_lamps.py`: read the file as lines; a placement is the line(s) from the one containing `id: <pid>` AND `ref:` through balanced braces; edit `ref:` and `at:` with `re.sub` on that span only; delete a removed lamp's span; for the version use `re.sub(r"^version: .*$", ..., flags=re.M)` once.

"""#125 sweep: every RJ45 onto the four-part family, lamps into the jack.

THE RULE DECIDES, NOT THIS FILE. Which part a jack takes comes from
lint.rj45_wants_lamps - the same test L76 counts with - so the sweep cannot
disagree with the census that checks it.

THE REWRITE IS TEXTUAL, like sweep_ids.py and sweep_jack_lamps.py: these files
carry paragraphs of provenance as block scalars, and a yaml round-trip reflows
all of it. A placement is the line carrying `id: X` and `ref:`, through balanced
braces; only that span is edited.

EVERY JACK HOLDS ITS CENTRE. The new part is a different size from the old; the
anchor moves by half the difference so the plug interface does not move on any
faceplate.

    sweep_rj45.py --library library [--devices DIR] [--components] [--apply] [fragment ...]
"""
import argparse
import collections
import glob
import pathlib
import re
import sys

sys.path.insert(0, str(pathlib.Path(__file__).resolve().parent))
import yaml
import lint as L

ap = argparse.ArgumentParser(description=__doc__.split("\n")[0])
ap.add_argument("--library", default="library")
ap.add_argument("--devices", help="device tree to sweep (default: <library>/devices)")
ap.add_argument("--schemas", default="spec/schemas")
ap.add_argument("--components", action="store_true", help="sweep parts: in component contracts instead")
ap.add_argument("--apply", action="store_true")
ap.add_argument("only", nargs="*")
ARGS = ap.parse_args()
LIB = ARGS.library
ROOTS = [LIB]
if not L.STANDARDS:
    L.STANDARDS.update(yaml.safe_load(
        (pathlib.Path(ARGS.schemas) / "standards.yaml").read_text())["standards"])

SINGLE = {"std/rj45@1", "common/rj45-port@4", "common/rj45-bezel@2", "common/rj45-shielded@1",
          "common/rj45-shielded@2", "common/rj45-jack@2"}
GANGED = {"std/rj45-ganged@1", "common/rj45-hd@1", "common/rj45-hd-plain@1"}


def target(ref, lamps):
    if ref in SINGLE:
        return "common/rj45-eth@1" if lamps else "std/rj45@2"
    if ref in GANGED:
        return "common/rj45-ganged-eth@1" if lamps else "std/rj45-ganged@2"
    return None


def size(ref):
    s = L.contract_size(ref, ROOTS)
    return (s["w"], s["h"])


def cls(ref):
    cp = L.resolve_component(ref, ROOTS) if ref else None
    return (L.load_yaml(cp) or {}).get("class") if cp else None


def span(rows, pid):
    """(start, end) line indexes of the placement whose flow mapping carries id: pid."""
    for i, l in enumerate(rows):
        if re.search(rf"\bid: {re.escape(pid)}[,}}\s]", l) and "ref:" in "".join(rows[i:i + 3]):
            depth, j = 0, i
            for j in range(i, len(rows)):
                depth += rows[j].count("{") - rows[j].count("}")
                if depth <= 0:
                    break
            return i, j
    return None


def cutout_span(rows, pid):
    for i, l in enumerate(rows):
        if re.search(rf"\bid: {re.escape(pid)}[,}}\s]", l) and "ref:" not in l and "size:" in l:
            return i, i
    return None


def fmt(v):
    return f"{v:.2f}".rstrip("0").rstrip(".") if isinstance(v, float) else str(v)


def edit_at(text, dx, dy):
    m = re.search(r"at: \[\s*(-?[\d.]+)\s*,\s*(-?[\d.]+)\s*\]", text)
    x, y = float(m.group(1)) + dx, float(m.group(2)) + dy
    return text[:m.start()] + f"at: [{fmt(round(x, 2))}, {fmt(round(y, 2))}]" + text[m.end():]


def bump(version, level):
    a, b, c = (int(x) for x in version.split("."))
    return f"{a + 1}.0.0" if level == "major" else f"{a}.{b + 1}.0"


def sweep_device(path):
    data = yaml.safe_load(open(path))
    rows = pathlib.Path(path).read_text().split("\n")
    groups = data.get("groups") or {}
    report = collections.Counter()
    removed_ids, unresolved = [], []
    for vname, view in (data.get("views") or {}).items():
        pl = (((view or {}).get("components") or {}).get("placements")) or []
        by_id = {str(q["id"]): q for q in pl}
        moves = {}
        for q in pl:
            ref = str(q.get("ref") or "")
            new = target(ref, L.rj45_wants_lamps(q, groups))
            if new:
                moves[str(q["id"])] = (ref, new)
        lifted = collections.defaultdict(list)          # jack id -> [(x, lamp placement)]
        for q in pl:
            f = q.get("for")
            targets = f if isinstance(f, list) else [f]
            if cls(str(q.get("ref") or "")) != "led":
                continue
            for t in targets:
                t = str(t)
                if t in moves and moves[t][1].startswith("common/") and t in by_id:
                    jx, jy = by_id[t]["at"]; jw, jh = size(moves[t][0])
                    if (by_id[t].get("rotate") or 0) % 180 == 90:
                        jw, jh = jh, jw
                    x, y = q["at"]
                    if jx <= x <= jx + jw and jy <= y <= jy + jh:
                        lifted[t].append((x, q))
        # 1-2. move jacks, holding centres; 3. write lifted states onto them
        for pid, (old, new) in moves.items():
            s = span(rows, pid)
            if not s:
                unresolved.append(f"{vname}/{pid}: no placement line"); continue
            (ow, oh), (nw, nh) = size(old), size(new)
            block = "\n".join(rows[s[0]:s[1] + 1])
            block = block.replace(f"ref: {old}", f"ref: {new}", 1)
            block = edit_at(block, (ow - nw) / 2, (oh - nh) / 2)
            if lifted.get(pid):
                lamps = sorted(lifted[pid], key=lambda t: t[0])
                mapping = {}
                for name, (_, lamp) in zip(("led-a", "led-b"), lamps):
                    if lamp.get("states"):
                        mapping[name] = lamp["states"]
                    elif (lamp.get("attrs") or {}).get("function"):
                        mapping[name] = ["off", {"name": lamp["attrs"]["function"]}]
                if mapping:
                    inline = yaml.safe_dump(mapping, default_flow_style=True, width=10 ** 6).strip()
                    block = block[:block.rstrip().rfind("}")] + f", states: {inline}" + "}"
            rows[s[0]:s[1] + 1] = block.split("\n")
            report["lamped" if new.startswith("common/") else "bare"] += 1
        # 3b. remove the lifted lamps
        for pid, lamps in lifted.items():
            for _, lamp in lamps:
                s = span(rows, str(lamp["id"]))
                if s:
                    del rows[s[0]:s[1] + 1]
                    removed_ids.append(str(lamp["id"])); report["lamps lifted"] += 1
        # 5. cutouts
        for pid, (old, new) in moves.items():
            s = cutout_span(rows, pid)
            if not s:
                continue
            (ow, oh), (nw, nh) = size(old), size(new)
            line = rows[s[0]]
            line = re.sub(r"size: \[\s*[\d.]+\s*,\s*[\d.]+\s*\]", f"size: [{fmt(nw)}, {fmt(nh)}]", line)
            line = re.sub(r"size: \{w: [\d.]+, h: [\d.]+\}", f"size: [{fmt(nw)}, {fmt(nh)}]", line)
            rows[s[0]] = edit_at(line, (ow - nw) / 2, (oh - nh) / 2)
            report["cutouts resized"] += 1
    text = "\n".join(rows)
    # 4. legends: a `for:` naming a removed lamp names the jack instead
    for lid in removed_ids:
        jack = next((t for t in yaml.safe_load(text).get("views", {}).values() for _ in [0]), None)
    if removed_ids:
        d2 = yaml.safe_load(text)
        owner = {}
        for view in (d2.get("views") or {}).values():
            for q in (((view or {}).get("components") or {}).get("placements") or []):
                pass
        # the lamp's `for:` said which jack it belonged to; read it off the ORIGINAL data
        for view in (data.get("views") or {}).values():
            for q in (((view or {}).get("components") or {}).get("placements") or []):
                if str(q.get("id")) in removed_ids:
                    f = q.get("for"); owner[str(q["id"])] = str(f[0] if isinstance(f, list) else f)
        for lid, jack in owner.items():
            n = len(re.findall(rf"for: {re.escape(lid)}\b", text))
            text = re.sub(rf"for: {re.escape(lid)}\b", f"for: {jack}", text)
            text = re.sub(rf"(for: \[[^\]]*?)\b{re.escape(lid)}\b", rf"\1{jack}", text)
            report["legends re-pointed"] += n
            for key in ("members", "scope", "combo-with"):
                if re.search(rf"{key}:[^\n]*\b{re.escape(lid)}\b", text):
                    unresolved.append(f"{key} still names removed lamp {lid}")
    # 6. version
    if removed_ids or report["lamped"] or report["bare"]:
        level = "major" if removed_ids else "minor"
        text = re.sub(r"^version: (\S+)$", lambda m: f"version: {bump(m.group(1), level)}", text, count=1, flags=re.M)
        report[f"bump {level}"] = 1
    return text, report, unresolved

    rows = pathlib.Path(path).read_text().split("\n")
    report = collections.Counter()
